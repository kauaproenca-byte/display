# 📐 Estudando CSS `display`

Projeto criado para estudar e praticar os diferentes valores da propriedade `display` do CSS, entendendo como cada um altera o comportamento e o posicionamento dos elementos na página.

## 🎯 Objetivo

Explorar, na prática, os principais tipos de `display` e seus casos de uso, observando como os elementos se comportam dentro do layout.

## 📚 Displays estudados

- `block` — ocupa toda a largura disponível e inicia uma nova linha.
- `inline` — ocupa apenas o espaço necessário e permanece na mesma linha.
- `inline-block` — combina características de `inline` e `block`.
- `flex` — facilita a criação de layouts unidimensionais e o alinhamento de elementos.
- `grid` — permite criar layouts bidimensionais com linhas e colunas.
- `none` — remove o elemento da renderização da página.
- `inline-flex` — cria um container flexível que se comporta como um elemento inline.
- `inline-grid` — cria um container grid que se comporta como um elemento inline.
